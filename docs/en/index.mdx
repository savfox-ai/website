## Quick Path

<Steps>
  <Step title="Install">

```bash
git clone https://github.com/savfox-ai/savfox.git
cd savfox
cargo install --path crates/savfox-cli
```

  </Step>
  <Step title="Login">

```bash
savfox login
```

  </Step>
  <Step title="Run">

```bash
savfox
```

  </Step>
</Steps>
