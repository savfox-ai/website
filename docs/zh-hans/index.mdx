## 快速路径

<Steps>
  <Step title="安装">

```bash
git clone https://github.com/savfox-ai/savfox.git
cd savfox
cargo install --path crates/savfox-cli
```

  </Step>
  <Step title="登录">

```bash
savfox login
```

  </Step>
  <Step title="运行">

```bash
savfox
```

  </Step>
</Steps>
